# Security Policy

## Supported Scope

Security reports are accepted for the code in this repository, including the agent, server, dashboards, and deployment configuration.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to `y13308074856@gmail.com`.

Include:

- affected component and version or commit
- reproduction steps or proof of concept
- impact assessment
- any mitigation you have already tested

Please do not open a public issue for an unpatched vulnerability.

## Response Expectations

- Initial acknowledgement target: within 7 days
- Follow-up with triage status when the issue is reproduced or rejected
- Public disclosure after a fix is available or a coordinated disclosure date is agreed
